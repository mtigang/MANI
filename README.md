# MANI

MANI is a 3D browser-based game built with **Three.js**, **TypeScript** and **Vite**.

## Story (Chapter 1)

- Intro / title screen
- Main menu (3 options)
- Settings
- 16-second intro video
- Mani's room
- Corridor & staircase
- Exit the building
- Iranian street scene
- Closed path on the right, open path on the left
- Fire truck and police car pass by
- Reach the police station ~100 m ahead
- Crowd gathered in front of the station
- End of Chapter 1

## Controls

**Desktop**
- WASD – move
- Mouse – look
- Shift – run
- E – interact
- Esc – pause

**Mobile**
- Left virtual joystick – move
- Right touch – camera
- On-screen buttons for run / interact / pause

## Development

```bash
npm install
npm run dev
```

## Deployment

GitHub Pages via GitHub Actions. Base path is `/MANI/`.
